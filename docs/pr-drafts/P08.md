# P08: Self-healing proposal engine with fixed model weights

## Summary
- Added `ErrorCluster`, `PolicyPatch`, and `RepairCandidate` into `backend/app/schemas.py` to structure self-healing patches cleanly.
- Implemented `FailureMiner` in `backend/app/repair/miner.py` which clusters exclusively semantic errors on the development set into groups mapped by `(true_label, predicted_label)`. Infrastructure errors are intentionally filtered out.
- Implemented `PolicyProposer` in `backend/app/repair/proposer.py` ensuring that the engine only returns structured, bounded patch variants.
- The proposer strictly locks out restricted files (`schemas.py`, benchmark data, evaluator rules, etc.) keeping edits focused only on definitions and runtime tuning parameters to prevent evaluator rewriting.

## Evidence
- Automated tests in `backend/tests/test_repair.py` verify that valid clusters are successfully generated for semantic misclassifications, and that attempting to patch locked domain files safely throws a `ValueError`.
- Metrics and validation run properly indicating structural logic for proposing delta candidates works as intended.
